# 返済と家計簿 Webアプリ（完全無料版）

- スマホ対応
- 家計簿・債権者・生活費を後から編集可能
- 自動保存
- JSONバックアップ/復元
- CSV出力
- PWA対応（ホーム画面追加）
- Service Workerでオフライン利用対応
- 有料サーバー・有料DB不要

## 無料でスマホからいつでも使う方法
GitHub Pages / Cloudflare Pages / Netlify等の無料静的ホスティングにこのフォルダを公開してください。
公開後のURLをスマホで開き、ホーム画面に追加するとアプリのように使えます。

データは各端末のブラウザ内に保存されます。複数端末間の自動同期はありません。
機種変更前やブラウザデータ削除前は必ず「バックアップ」を実行してください。
